# PRISM - Video Title Generation

Multimodal Transformer for automatic video title generation using visual (CLIP), textual (OCR/ASR via BERT), and audio (YAMNet) features.

**Ground truth titles are generated using Qwen2-VL** vision-language model, then used to train a lightweight multimodal transformer.

## Architecture

### Pipeline
```
Videos (Google Drive)
    │
    ▼
┌──────────────┐
│  Qwen2-VL    │  ← Step 1: Generate ground truth titles
│  (VLM)       │
└──────┬───────┘
       │ vlm_titles.csv
       ▼
┌──────────────┐    ┌──────────────┐
│ CLIP Visual  │    │  BERT Text   │
│ Features     │    │  OCR + ASR   │
│ (512-dim)    │    │  (768→512)   │
└──────┬───────┘    └──────┬───────┘
       │                   │
       ▼                   ▼
    ┌─────────────────────────┐
    │ [visual, ocr, asr]      │  3 modality tokens (3 × 512)
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ Transformer Encoder     │  3 layers, 8 heads
    │ (Multimodal Fusion)     │
    └───────────┬─────────────┘
                │ memory
                ▼
    ┌─────────────────────────┐
    │ Transformer Decoder     │  3 layers, 8 heads
    │ (Autoregressive)        │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ FC → Vocabulary         │  Greedy decoding
    └─────────────────────────┘
                │
                ▼
         Generated Title
```

### Model Details
- **Input:** 3 modality tokens (CLIP visual 512d, BERT-OCR 512d, BERT-ASR 512d)
- **Encoder:** 3 Transformer encoder layers (8 heads) fuse the multimodal tokens
- **Decoder:** 3 Transformer decoder layers (8 heads) generate title tokens autoregressively
- **Output:** Vocabulary projection → greedy decoding

### VLM Labeler (Qwen2.5 -VL)
- Default model: `Qwen/Qwen2.5-VL-2B-Instruct` (fits on Colab T4)
- Processes each video and generates a descriptive title
- Supports resume (saves progress every 10 videos)
- Can use `Qwen/Qwen2-VL-7B-Instruct` on A100 GPUs
